# 万维钢.skill v1.1.0 Phase 5：Skill Creator 独立精炼审查

- 审查日期：2026-08-15
- 审查角色：Agent B（Skill Creator 视角）
- 审查对象：仓库根目录 `SKILL.md`、`README.md`、`10-synthesis-2026-08.md` 与 Phase 4 四份验证记录
- 审查范围：触发准确性、角色协议可操作性、问题路由、研究与停止条件、推断归因、回答预算
- 结论：**不阻断发布；建议发布前合入以下 3 处小改动。**三处都只改变运行规则，不扩写人物知识或心智模型。

## 一、总体判断

当前候选版已经具备可运行 Skill 的主要条件：

1. `frontmatter` 同时说明了人物、能力与使用场景，显式点名人物时能稳定触发；
2. `Step 1` 已把问题分为事实、框架和混合三类，四种领域研究路由也足够具体；
3. 首次免责声明、部分模型调用、情绪处理、模型冲突和退出角色都有明确动作；
4. Phase 4 的已知、边缘、文风和结构测试均为 PASS，尤其验证了事实/推断分层与高风险边界。

剩余问题不在框架内容，而在三个执行边界：

- **容易误触发**：`系统思维`、`第一性原理`、`科学家的角度`、`拆解决策` 都是跨 Skill 的通用表达，单独列为强触发会抢占中性分析或其他人物 Skill；
- **角色透明度不够稳定**：开头要求“直接以万维钢的身份回应”，又声明“非本人观点”，执行模型可能在沉浸式角色与透明推断之间摇摆；首次免责声明也不能覆盖后续新出现的具体政策或事件推断；
- **缺少失败出口**：`必须使用工具，不可跳过` 没说明工具不可用、关键事实查不到或高风险个体信息不足时怎么办；固定“超过 1 小时重查”也没有按信息波动性判断，可能造成不必要的研究。

## 二、建议改动 1：收紧通用词触发，保留人物与标志性框架的强触发

### 位置

`SKILL.md` YAML `description` 的最后两行触发说明。

### 建议改后文本

```yaml
  当用户明确提到「万维钢」「同人于野」「万Sir」「万维钢会怎么看」「精英解法」「现代思维工具100讲」「Wanweigang perspective」时使用。
  当用户未点名人物，但同时要求用理工科或科学方法分析，并涉及目标函数、参考类、反馈系统、概率与不确定性、避免出局、探索和生发中的至少一种标志性任务时，也应触发。
  仅出现「系统思维」「第一性原理」「科学家的角度」「拆解决策」等通用表达，不足以单独触发；此时优先作中性分析，除非用户明确要求人物视角。
```

### 预期效果

- 保留“人物名、课程名、精英解法”等高精度入口；
- 对隐式需求仍然偏积极触发，但要求“分析方式 + 标志性任务”形成组合信号；
- 减少与通用系统思维、第一性原理、科学顾问类 Skill 的竞争和误触发；
- 顺带修正现有英文 `Wanweigan` 少一个 `g` 的拼写。

## 三、建议改动 2：把“扮演本人”改成“透明运行人物视角”，增加局部推断标签与回答预算

### 位置

`## 角色扮演规则（最重要）` 开头，替换从“此 Skill 激活后……”到“不跳出角色做 meta 分析……”这一组身份规则；情绪、高风险、部分使用和退出角色规则保留。

### 建议改后文本

```markdown
**此 Skill 激活后，以万维钢视角回应，但不声称自己就是万维钢本人。**

- 在角色化分析中用「我」表达判断，保持万维钢的语气、节奏和词汇；不要写成旁观者传记，也不要伪造本人原话、私下动机或未公开立场。
- 首次激活时只说一次：「我以万维钢视角和你聊，以下依据公开言论和著作推断，不代表本人观点。」后续纯框架分析不重复。
- 即使已经做过首次免责声明，遇到万维钢未公开讨论的具体机构、人物、事件或政策，仍在相关判断前局部标注一次「以下是依据公开框架作的推断」；事实、框架推断、未知信息和价值选择不得混写。
- 用户指定的长度、语气和输出格式优先于角色默认文风。默认只调用 1—2 个最有区分力的模型；简单问题不强行套完整五段流程，每个回答通常最多使用一个类比，避免口头禅和框架压倒用户意图。
- 不跳出角色作无关的 meta 分析；用户要求核对依据、区分本人观点或退出角色时，直接透明说明。
```

### 预期效果

- 消除“我是本人”与“非本人观点”的指令张力，降低冒充和错误归因风险；
- 首次免责声明控制重复频率，局部推断标签则覆盖后续新场景，两者职责清楚；
- 把 Phase 4 边缘测试中表现良好的事实/推断分层固化为规则；
- 限制模型、类比和固定结构的使用频率，短问短答时不被人物文风反客为主。

## 四、建议改动 3：为实时研究和高风险问题增加明确的暂停、停止与降级动作

### 位置

`### Step 2: 万维钢式研究` 开头，替换现有的“必须使用工具，不可跳过”单句；同时将 `中断恢复协议` 中“间隔超过 1 小时就重新研究”改为按信息波动性判断。

### 建议改后文本

```markdown
### Step 2: 万维钢式研究（按问题类型选择）

需要实时或个案事实才能判断时，使用当前获准且可用的研究工具核实；不要用记忆补齐最新数据。执行以下研究闸门：

1. **先列关键未知量**：只查可能改变判断或行动的信息，优先一手、官方和专业来源；关键时效事实在回答中注明来源与日期，但不把答案写成资料堆砌。
2. **失败时暂停结论**：若工具不可用、关键来源无法核实，或用户没有提供决定性的个案信息，明确列出「已知、未知、还需什么证据」，暂停作确定结论；可以请求材料或给条件式分支，不得凭训练记忆补完。
3. **高风险时降级**：医疗、法律、金融、公共安全等问题若缺少个体条件、适用规范或专业审查，只提供问题清单、证据路径、风险边界和求助方向，不给个体化诊断、交易指令、法律结论或危险操作步骤。
4. **按信息价值停止**：当新增信息不再改变当前可选行动，或已达到专业人士接手的边界，就停止研究并说明剩余不确定性。
```

将中断恢复协议中的对应规则改为：

```markdown
2. **事实验证**：若先前结论依赖可能已经变化的实时事实，按该事实的更新频率和决策敏感性重新执行 Step 2；不要仅因对话间隔超过固定时长就机械重查。
```

### 预期效果

- “必须研究”不再是一条没有退路的命令，工具失败和证据不足都有确定行为；
- 明确区分“暂停结论”与“停止研究”，既防编造，也避免无限搜索；
- 把高风险边界从原则声明变成可执行的输出降级规则；
- 用信息波动性替代固定一小时阈值，减少稳定事实的重复调研，同时不会放过价格、政策、市场等真正易变信息。

## 五、是否阻断发布

**不阻断。** Phase 4 已证明候选版可以还原已知立场、处理未知边缘问题并保持辨识度；结构指标也全部达标。上面三项属于运行可靠性精炼，不涉及重新提炼模型或追加材料。

发布建议：优先全部合入；若只能合入一项，优先级为 **改动 3（研究/高风险闸门） > 改动 2（透明角色与回答预算） > 改动 1（触发精度）**。合入后用现有四组验证做一次静态回归即可，无需重跑整套调研。
