# GitHub 首页 Hero 海报设计

## 目标

为 `WanWeigang.skill` 仓库制作一张长期使用的首页 Hero 海报。它应在 GitHub README 首屏建立强识别度，同时准确表达本项目是“可运行的思维操作系统”，不是课程广告或人物应援图。

## 已确认方向

采用无真人的“思维反应堆”方案：以抽象系统、轨道、节点和能量流表现模型、反馈、不确定性与生发。

## 画面规格

- 画布：16:9 横版，目标尺寸 1600×900
- 使用位置：README 主标题之后、徽章之前
- 背景：深空蓝黑，保留足够暗部和负空间
- 主体：右侧透明发光的认知核心，外部形成7层轨道与10个节点
- 动势：红金能量流穿过冷蓝结构，形成“约束中的生成”
- 质感：精密工程、科学仪器、现代编辑设计；克制而非堆砌

## 文案层级

图片只保留四组文字：

1. `万维钢.skill`
2. `MODERN THINKING OPERATING SYSTEM`
3. `7 MENTAL MODELS · 10 HEURISTICS`
4. `v1.1.0`

标题应在缩略图下仍可辨认，其余文字不得抢占主视觉。

## 色彩

- 深空蓝黑：主背景
- 电光蓝：系统结构与轨道
- 中国红：关键能量流与视觉锚点
- 少量金色：节点、版本或关键高光
- 白色：主标题

## 明确避免

- 真人、剪影或风格化肖像
- AI大脑、机器人头、代码雨等陈词滥调
- 廉价霓虹赛博朋克、过度镜头光晕和高饱和渐变
- 课程广告式“震撼首发”文案
- 无关Logo、水印、伪造引用或额外小字
- 中文乱码、重复标题或错误的模型/启发式数字

## 交付与集成

- 最终文件：`assets/wanweigang-skill-hero-v1.1.0.png`
- README 使用相对路径嵌入，并提供说明性 alt 文本
- 不覆盖现有 `poster_wechat.png` 和 `poster_tiktok.png`
- 图片进入 Git 仓库，随后提交并推送 `main`

## 验收标准

1. 主标题和三组辅助文案准确，无乱码、重复或多余字符。
2. 画面在 README 宽度和手机缩略图下仍有清晰层级。
3. 视觉能读出系统、反馈、轨道和生成，而不是通用AI宣传图。
4. 7个模型、10条启发式和 `v1.1.0` 信息准确。
5. README Markdown 可正常显示，图片路径有效。
6. 推送后 GitHub `main` 与本地提交一致。
